A2 · The census pipeline — published, runnable

The conditional-census pipeline behind §9.2’s runs is published in this repository under scripts/census/ — estimator source, single-map wrapper, the hardening and verdict shell scripts exactly as run, the verdict-leg result JSONs (full Γ*(r) profiles with settings echoed inline) and logs, and a README with the full run record. The load-bearing facts:

  • Estimator: conditional integrated density $\Gamma^*(r) = \langle n(<r)\rangle$ over every embedded galaxy centre; embedding decided per centre per scale against a radially-resolved random-count expectation (fill threshold 0.97; 0.90/0.99 run as the criterion systematic); footprint solid angle from 0.5° cells of the randoms; weighted mean (catalogue WEIGHT); 100-fold bootstrap over centres; fixed seeds. $D_2 = 3 + $ slope of the weighted log–log fit.
  • Three z→distance maps, coefficients fixed in advance: flat ΛCDM (H₀ = 70, Ωm = 0.3 — the Sylos Labini & Antal fiducial); cosmography Taylor-3 and Padé(2,1) from SN-only coefficients (q₀ = −0.55, j₀ = 1.0, H₀ = 73); the Taylor–Padé spread is the truncation systematic. No FLRW enters the model-independent legs.
  • Data: DESI DR1 LSS clustering catalogues (BGS_BRIGHT-21.5, LRG, ELG_LOPnotqso, QSO; both caps; public, CC BY 4.0). Mocks: AbacusSummit dark v4.2 — complete, ffa, and altmtl0 flavors, downloaded and run by the verdict scripts as published.
  • Run record: v1 baseline 2026-08-23; hardening 2026-08-27 (z-slices, matched depth/density, refits, controls); weights/scramble/amplitude 2026-08-28; verdict legs 2026-08-29 (turnover grids to 260–300 Mpc, mock control + realization scatter, ffa, alt-MTL — the residual’s decider: D₂ = 2.922/2.906 vs data 2.921/2.907, environment test). Verbatim logs for all four verdict legs ship with the scripts.
  • Honest bounds: the full 66-JSON result set and the multi-GB catalogues live off-repo (sizes); the published JSONs cover every number quoted on the suite’s pages. Statistical errors ±0.001-class throughout — systematics own the error budget, which is why the mock controls decide.
