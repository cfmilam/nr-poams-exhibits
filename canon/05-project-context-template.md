# Project-specific context

Complete these fields after the source reading. An unknown stays unknown; a requested decision is not an approval.

```text
QUESTION — The owner's question, in the owner's words.
PHENOMENON — Observer or interagent; record; interpretation kept separate.
SOURCE POSITION — Canon page/version; exact passages and locations; conflicts and missing rules.
GROUNDING — Relevant constraints; applicable governing sections.
ADDED PREMISES — Physical premises and imported mathematics listed separately; scope and failure conditions.
APPROACHES — Alternatives considered, chosen approach, and reason for the choice.
DEFEATING RECORD — Exact observation or logical result that would defeat the claim.
REVIEW AND AUTHORITY — Input versions; independent review result; authorized scope; no invented approval.
STOP AND BUDGET — Active stop signals; remaining work, time, and cost limits.
SOURCE ACCESS — Supplied documents and verified locations; missing source access stated explicitly.
```
